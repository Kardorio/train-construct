Aperçu hors jeu des sprites réellement branchés au mod

Recomposition des PNG sources par les rectangles, échelles et décalages du contrat Lua testé. Ce document n’est pas une capture de Factorio ; les rails sont des repères schématiques.

Chaque vue couvre 40 × 40 cases. Grille : 1 case. Origine du module : (0, 0) ; centre de voie : (1, 1). Longueur calibrée : 32 cases ; couloir libre : ±1,5 case. Les toitures peuvent déborder de la sélection nominale de 12 × 32 cases.

Le bâtiment représente le stock intégré. Les poutres et les dalles restent complètes ; un sol métallique relie les deux côtés sous les vrais rails.

Vert : couloir du train ; beige : sélection nominale ; bleu : rectangles sources.
